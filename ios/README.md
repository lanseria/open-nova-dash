# NovaDash iOS

联咏（Novatek 860N72-SF20200714）行车记录仪的控制 APP。协议能力与坑位说明见仓库根目录 `readme.md` 与 `iOS.md`（全部来自 `script.py` 五轮实测）。

## 功能（v0.1）

- **状态**：固件版本 / 电池 / SD 卡 / 剩余空间（3012/3019/3024/3017），心跳保活（3016，3 秒一次，失败退避）
- **相册**：SD 卡文件列表（3015，-3 时自动走回放模式流程），按照片/视频筛选；下载（hfs 服务器，实测 URL 规则：去掉 `A:` 盘符前缀）、照片存系统相册、TS 视频下载后自动重封装为 MP4 再分享导出
- **本地相册**：展示文档目录里已下载/下载中的视频与照片（下载进度跨 tab 实时可见），视频可在线播放、照片可查看/存相册，均支持分享；文件保存在系统"文件"App（我的 iPhone → NovaDash）可直取
- **本地相册删除**：支持在本地相册中删除单个文件，或进入选择模式批量勾选、全选后一次删除；仅移除 App 文档目录中的下载文件，不影响系统相册已保存内容。
- **控制**：远程拍照（1001，-22 时自动切换模式拍照）、录像开始/停止（2001&str，-22 语义化为"已处于目标状态"）
- **控制台**：发往设备的每一次请求（CGI/心跳/下载/缩略图）与直播/在线播放事件都记录在案（环形缓冲 300 条），支持筛选/搜索/暂停/复制/清空，用于排查控制无效果、超时、无法重播等问题

## 2026-09-20 优化记录

- **拍照提速**：切模式后不再盲等固定秒数（原 2s + 1.5s），改为轮询 3037 工作模式到位即走（4s 兜底），全程省 2~4 秒
- **直播低延迟**：调低 KSPlayer 三个默认值 —— FFmpeg 流探测 5s→1s（probesize 512KB）、起播缓冲 3s→0.5s、最大缓存 30s→1.5s（防止延迟越积越多），起播约 1~2 秒画面
- **修复"停止后无法再次播放"**：直播与相册在线播放每次都使用全新播放会话（新 Coordinator + 视图身份重建），停止时显式 `stop()` 立即关闭 RTSP/HTTP-TS 连接（`resetPlayer` 内部只 pause 不释放，设备端会话/连接位不腾出会导致下次开播被拒、单线程 HTTP 服务被占死）；切码流时错开 800ms 等设备释放旧会话

## 运行

```bash
# 模拟器（共享 Mac 网络: Mac 连着记录仪 Wi-Fi 时可直接联调）
open NovaDash.xcodeproj   # Xcode 里选任一 iPhone 模拟器, Cmd+R

# 真机（需在 Xcode Signing & Capabilities 里选自己的开发者账号/Team）
```

命令行验证编译：

```bash
cd ios
xcodebuild -project NovaDash.xcodeproj -target NovaDash -sdk iphonesimulator \
  -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

## 首次运行注意

1. iOS 会在首次访问 `192.168.1.254` 时弹**本地网络权限**，必须允许；
2. 记录仪 Wi-Fi 无外网，iOS 可能提示"无法接入网络"——选择**保持连接**（客户端已禁用蜂窝回退）；
3. 保存照片需**相册写入权限**；
4. 当前卡快满（0.2GB）时拍照/录像会失败（-5/-22），请先在设备上格式化。

## 架构红线（驱动层已实现，改动前先读 readme"坑位说明"）

- 固件 HTTP 服务器**单线程**：所有请求（含心跳）经 `AsyncSemaphore` 串行，心跳忙时让路；
- **读超时不重发**状态命令（可能重复执行）；
- 重命令（录像/切模式）长超时（12~15s），"超时 ≠ 命令失败"；
- 下载 URL = 原始路径去掉 `A:` 前缀；hfs 服务器不复用连接。

## 2026-09-30 优化记录

- **TS 视频下载即转 MP4**：下载完成后用 libavformat（裸 C API，`Core/TSRemux.swift`）把 MPEG-TS 无转码重封装为 MP4——编码参数原样拷贝（画质无损，速度接近文件拷贝），hfs 的 H.264 tag（0x1B）清零让 MP4 复用器自选 avc1，HEVC 显式指定 hvc1（Apple 生态不认 hev1），并减去 TS 非零起始时间戳（典型 1.4s 初始延迟，原样写入会变成开头空白段）。转换成功删除中间 TS；失败降级保留原始 TS 并提示。H.264/H.265 样本均通过 AVFoundation 可播性校验。
- **新增"本地相册" tab**：TabView 常驻（未连接 = 设备+本地相册，连接后 = 控制/状态/控制台/本地相册，离线也能看已下载内容）。列表实时展示设备相册页发起的下载进度（AlbumModel 单例化共享状态），已完成文件带封面卡片（视频 FFmpeg 抽首帧、照片 ImageIO 降采样）；文档目录经 `UIFileSharingEnabled` 暴露给系统"文件"App，可在系统端管理。
